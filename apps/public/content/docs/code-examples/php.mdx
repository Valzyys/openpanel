## PHP

PHP is one of the oldest and most widely used server-side languages. Interacting with the JKT48Connect API can be done minimally using standard functions or robustly through `cURL` for more advanced setups.

### Using `file_get_contents` (The Easy Way)

The quickest way in PHP is to use `file_get_contents()`. Ensure that `allow_url_fopen` is enabled in your `php.ini` configuration.

```php
<?php

$apiKey = 'YOUR_API_KEY';
$endpoint = 'members';
$url = "https://v2.jkt48connect.com/api/jkt48/{$endpoint}?apikey={$apiKey}";

// Fetch data
$jsonResponse = file_get_contents($url);

if ($jsonResponse === false) {
    die('Failed to fetch data from the API.');
}

// Decode the JSON string into an associative array
$data = json_decode($jsonResponse, true);

if (json_last_error() !== JSON_ERROR_NONE) {
    die('JSON parsing failed: ' . json_last_error_msg());
}

$total = count($data);
echo "Successfully fetched {$total} members.\n";

// Display names
foreach ($data as $member) {
    echo "- " . $member['name'] . "\n";
}
```

### Using `cURL` (Recommended Approach)

If you are building a serious application, it is highly recommended to use the cURL extension, which handles HTTP requests and responses more robustly:

```php
<?php

function getJKT48Data($endpoint) {
    $apiKey = 'YOUR_API_KEY';
    $baseUrl = 'https://v2.jkt48connect.com';
    $url = "{$baseUrl}/api/jkt48/{$endpoint}?apikey={$apiKey}";

    $ch = curl_init();
    
    // Set cURL options
    curl_setopt($ch, CURLOPT_URL, $url);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_FOLLOWLOCATION, true);
    
    // Execute cURL request
    $response = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $errorInfo = curl_error($ch);
    
    // Close the connection
    curl_close($ch);
    
    if ($response === false) {
        throw new Exception("cURL Error: " . $errorInfo);
    }
    
    if ($httpCode !== 200) {
        throw new Exception("HTTP Error Code: " . $httpCode);
    }
    
    return json_decode($response, true);
}

// Usage Example
try {
    $events = getJKT48Data('events');
    echo implode(", ", array_column($events, 'title'));
} catch (Exception $e) {
    echo "Failed: " . $e->getMessage();
}

```

### Practical Example: Displaying Theater Schedule in HTML

Here is a practical implementation to render theater schedule details directly from a PHP backend into an HTML page.

```php
<?php
// (Make sure the getJKT48Data function is defined as above)

$schedule = [];
$error = '';

try {
    $schedule = getJKT48Data('theater');
} catch (Exception $e) {
    $error = $e->getMessage();
}
?>
<!DOCTYPE html>
<html>
<head>
    <title>JKT48 Theater Schedule</title>
</head>
<body>
    <h1>Upcoming Theater Shows</h1>
    
    <?php if ($error): ?>
        <p style="color:red;"><?php echo htmlspecialchars($error); ?></p>
    <?php elseif (empty($schedule)): ?>
        <p>No theater schedules at the moment.</p>
    <?php else: ?>
        <ul>
            <?php foreach ($schedule as $show): ?>
                <?php if (!empty($show['is_upcoming'])): ?>
                    <li>
                        <strong><?php echo htmlspecialchars($show['title']); ?></strong><br>
                        Setlist: <?php echo htmlspecialchars($show['setlist']); ?><br>
                        Date: <?php echo htmlspecialchars($show['date']); ?><br>
                        Members: <?php echo htmlspecialchars(implode(', ', $show['members'] ?? [])); ?>
                    </li>
                <?php endif; ?>
            <?php endforeach; ?>
        </ul>
    <?php endif; ?>
</body>
</html>
```
