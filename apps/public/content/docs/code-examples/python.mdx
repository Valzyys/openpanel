## Python

Python is an excellent choice for processing data from REST APIs. It is highly recommended to use the `requests` library to make API calls effortlessly.

### Installing the Library

Ensure you have installed the `requests` module:

```bash
pip install requests
```

### Basic Example: Get Members

```python
import requests
import json

API_KEY = 'YOUR_API_KEY'
BASE_URL = 'https://v2.jkt48connect.com'

def get_members():
    url = f"{BASE_URL}/api/jkt48/members"
    params = {'apikey': API_KEY}
    
    try:
        response = requests.get(url, params=params)
        
        # Raise an exception if the status != 200
        response.raise_for_status()
        
        data = response.json()
        print(f"Successfully fetched {len(data)} members.")
        
        # Display the first 3 member names
        for member in data[:3]:
            print(f"- {member['name']} ({member.get('generation', '')})")
            
        return data
        
    except requests.exceptions.HTTPError as err:
        print(f"HTTP Error: {err}")
    except Exception as err:
        print(f"Other error: {err}")

if __name__ == "__main__":
    get_members()
```

### Advanced Example: Simple Telegram Bot

Below is a code snippet demonstrating how to check if any members are live via a Telegram bot (requires `python-telegram-bot`):

```python
import requests

API_KEY = 'YOUR_API_KEY'

def get_live_status():
    url = f"https://v2.jkt48connect.com/api/jkt48/live?apikey={API_KEY}"
    try:
        data = requests.get(url).json()
        
        if not data:
            return "No members are currently live right now."
            
        message = "🔴 JKT48 Members Currently Live:\n\n"
        
        for member in data:
            platform = member.get('type', 'Unknown').upper()
            urls = member.get('streaming_url_list', [])
            link = urls[0]['url'] if urls else ""
            message += f"📺 [{platform}] {member['name']}\nLink: {link}\n\n"
            
        return message
    except:
        return "Failed to fetch live data."
```
