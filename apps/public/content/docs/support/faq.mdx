## Frequently Asked Questions

Temukan jawaban cepat untuk pertanyaan-pertanyaan yang sering diutarakan oleh komunitas pengguna API JKT48Connect.

### 1. Bagaimana cara mendapatkan API Key?

Kamu bisa mendapatkan atau membeli struktur API Key dengan mengikuti tautan di website resmi registrasi pada [jkt48connect.my.id/buyapi](https://www.jkt48connect.my.id/buyapi). Setelah mengisi formulir dan metode penyelesaian registrasi, kunci tersebut dapat digunakan tanpa durasi waktu spesifik per periode yang terbayar.

### 2. Apakah hasil array respon bersifat Real Time?

Sebagian respons API seperti Live Streaming (`/api/jkt48/live`) bersifat sedekat mungkin (real time). Kami memiliki bot sistem yang aktif terus melihat perubahan stream baik Showroom, IDN Live atau YouTube dan melakukan perbandingan data API setiap detiknya. Sifat data endpoint statis seperti Members Profiles direfresh setiap beberapa jam jika mendeteksi adanya transisi Gen baru, Pengumuman kelulusan Graduate mendadak, atau perubahan dari situs web operasional utama.

### 3. Bahasa Pemrograman apa yang bisa terintegrasi?

Semuanya. Layanan JKT48Connect murni berbentuk REST API via parameter URL, maka seluruh framework yang sanggup merender HTTP GET Call dan Parse Array JSON seperti PHP Server, NodeJS `fetch`/`axios`, Kotlin Android Apps, Flutter Mobile, C#, Ruby, Python, maupun sekadar Bash Linux Curl akan bisa menerapkannya secara utuh dan mulus.

### 4. Mengapa muncul "Invalid API Key" di response saya?

Setiap memanggil URL ke REST endpoints, harap masukkan kode kamu dengan penulisan parameter `apikey=` secara spesifik dengan lowercase yang disusul oleh deretan angka rahasianya.

```
https://v2.jkt48connect.com/api/jkt48/live?apikey=xxxxx-xxxx-xxxx...
```

Periksa spasi tambahan dan karakter kutip (" atau ') yang tanpa sengaja ikut terketik. Jika sudah dicek berulang dan tidak berhasil dengan pesan `403` kode kesalahan, besar kemungkinan API Key-mu hangus atau belum diaktifkan oleh admin; silahkan hubungi kontak Telegram admin yang terterra. 

### 5. Apakah layanan API open-source ini Gratis?

Terdapat tingkatan layanan prioritas server yang dikelola secara eksklusif. JKT48Connect bertujuan menyajikan arsitektur yang kuat dalam volume massa besar, sehingga diberlakukan iuran donasi / berlangganan `buy api` kecil untuk kelangsungan daya tahan server (sewa CPU/RAM /Bandwidth), namun kodenya sebagian besar mengedepankan pendekatan komunitas secara inklusif. Info detailnya mengenai ketersediaan opsi bebas (free) ada di portal utama.

### 6. Endpoint yang saya butuhkan (Misal: TikTok Live terbaru), apakah belum mendukung?

Sayangnya saat ini (pada iterasi versi terbaru) Live Streaming TikTok belum terekam dalam JSON Response Live kami, dan kami hanya melingkupi IDN Live (Bisa filter by keyword `idn`), Showroom (`showroom`), YouTube Live (`youtube`). Apabila terdapat tambahan platform lain dalam operasional resmi manajemen JKT48 kedepan, kami tentu mengusahakan penambahan field dan kapabilitas ekstra tanpa menghancurkan kode integrasimu yang kini berjalan.
