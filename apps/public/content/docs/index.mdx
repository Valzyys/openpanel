## ✨ Fitur Utama

- **👥 Data Member** — Profil lengkap semua member JKT48 aktif dan trainee
- **🎭 Jadwal Teater** — Informasi jadwal pertunjukan teater terbaru
- **📡 Live Streaming** — Data real-time member yang sedang live di IDN, Showroom, & YouTube
- **📰 Berita & Pengumuman** — Berita terbaru langsung dari JKT48
- **🎪 Event** — Daftar event dan off-air show JKT48
- **🎂 Ulang Tahun** — Informasi ulang tahun para member
- **🔑 Autentikasi Sederhana** — Cukup gunakan API key sebagai query parameter
- **⚡ Respons Cepat** — JSON response yang terstruktur dan konsisten
- **🌐 Platform Agnostic** — Bisa diakses dari bahasa pemrograman apapun

## 📊 Daftar Endpoint

| Endpoint | Deskripsi | Method |
|----------|-----------|--------|
| `/api/jkt48/members` | Daftar semua member JKT48 | GET |
| `/api/jkt48/live` | Live streaming dari semua platform | GET |
| `/api/jkt48/live/idn` | Live streaming dari IDN saja | GET |
| `/api/jkt48/theater` | Jadwal pertunjukan teater | GET |
| `/api/jkt48/news` | Berita dan pengumuman terbaru | GET |
| `/api/jkt48/events` | Daftar event JKT48 | GET |
| `/api/jkt48/birthday` | Ulang tahun member | GET |

## ⚡ Contoh Request Cepat

```bash
# Ambil semua data member JKT48
curl "https://v2.jkt48connect.com/api/jkt48/members?apikey=YOUR_API_KEY"

# Cek siapa yang sedang live
curl "https://v2.jkt48connect.com/api/jkt48/live?apikey=YOUR_API_KEY"

# Lihat jadwal teater
curl "https://v2.jkt48connect.com/api/jkt48/theater?apikey=YOUR_API_KEY"
```

## 🔑 Autentikasi

Semua request ke JKT48Connect API memerlukan API key. Tambahkan API key sebagai query parameter:

```
https://v2.jkt48connect.com/api/jkt48/{endpoint}?apikey=YOUR_API_KEY
```

Dapatkan API key di [jkt48connect.my.id/buyapi](https://www.jkt48connect.my.id/buyapi).
