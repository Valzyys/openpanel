## Autentikasi API

Semua endpoint JKT48Connect API memerlukan autentikasi menggunakan API key. API key dikirim sebagai query parameter di setiap request.

### Format Autentikasi

Tambahkan parameter `apikey` di URL request-mu:

```
https://v2.jkt48connect.com/api/jkt48/{endpoint}?apikey=YOUR_API_KEY
```

### Contoh Request dengan Autentikasi

```bash
# Mengambil data member
curl "https://v2.jkt48connect.com/api/jkt48/members?apikey=YOUR_API_KEY"

# Mengambil data live streaming
curl "https://v2.jkt48connect.com/api/jkt48/live?apikey=YOUR_API_KEY"

# Mengambil jadwal teater
curl "https://v2.jkt48connect.com/api/jkt48/theater?apikey=YOUR_API_KEY"
```

### Contoh dengan JavaScript

```javascript
const API_KEY = 'YOUR_API_KEY';
const BASE_URL = 'https://v2.jkt48connect.com';

async function fetchMembers() {
  const response = await fetch(`${BASE_URL}/api/jkt48/members?apikey=${API_KEY}`);
  
  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }
  
  const data = await response.json();
  console.log(data);
  return data;
}

fetchMembers();
```

### Contoh dengan Python

```python
import requests

API_KEY = 'YOUR_API_KEY'
BASE_URL = 'https://v2.jkt48connect.com'

def fetch_members():
    response = requests.get(f"{BASE_URL}/api/jkt48/members?apikey={API_KEY}")
    response.raise_for_status()
    data = response.json()
    print(data)
    return data

fetch_members()
```

### Response Jika API Key Tidak Valid

Jika API key yang diberikan tidak valid atau tidak disertakan, API akan mengembalikan error:

```json
{
  "status": false,
  "message": "Invalid API Key"
}
```

**HTTP Status Code**: `403 Forbidden`

### Mendapatkan API Key

Untuk mendapatkan API key:

1. Kunjungi [jkt48connect.my.id/buyapi](https://www.jkt48connect.my.id/buyapi)
2. Pilih paket yang sesuai
3. Selesaikan proses pembayaran
4. API key akan dikirimkan kepadamu

### Tips Keamanan

- **Jangan hardcode** API key di kode yang dipublikasi (misalnya di GitHub)
- Gunakan **environment variable** untuk menyimpan API key
- **Jangan share** API key-mu ke orang lain
- Jika API key bocor, segera hubungi support untuk penggantian

```bash
# Gunakan environment variable
export JKT48_API_KEY="your_actual_api_key_here"
```

```javascript
// Akses dari environment variable
const API_KEY = process.env.JKT48_API_KEY;
```

```python
import os
API_KEY = os.environ.get('JKT48_API_KEY')
```
