## Mulai Menggunakan JKT48Connect API

JKT48Connect API menyediakan akses ke data JKT48 melalui endpoint REST yang sederhana. Ikuti langkah-langkah berikut untuk memulai.

### Langkah 1: Dapatkan API Key

Untuk mengakses semua endpoint JKT48Connect API, kamu memerlukan API key.

1. Kunjungi [jkt48connect.my.id/buyapi](https://www.jkt48connect.my.id/buyapi)
2. Pilih paket yang sesuai kebutuhanmu
3. Selesaikan proses pembelian
4. Simpan API key yang diberikan

> **Penting**: Jangan bagikan API key-mu kepada orang lain. API key bersifat rahasia dan terikat pada akunmu.

### Langkah 2: Tentukan Base URL

Semua request ke JKT48Connect API menggunakan base URL berikut:

```
https://v2.jkt48connect.com
```

### Langkah 3: Kirim Request Pertamamu

Tambahkan API key sebagai query parameter `apikey` di setiap request:

```bash
curl "https://v2.jkt48connect.com/api/jkt48/members?apikey=YOUR_API_KEY"
```

### Langkah 4: Terima Response

Semua response dikirim dalam format JSON yang terstruktur:

```json
[
  {
    "name": "Shani Indira Natio",
    "generation": "JKT48 Gen 1",
    "status": "active"
  },
  {
    "name": "Fritzy",
    "generation": "JKT48 Gen 12",
    "status": "active"
  }
]
```

## Endpoint yang Tersedia

| Endpoint | Deskripsi |
|----------|-----------|
| `GET /api/jkt48/members` | Data semua member |
| `GET /api/jkt48/live` | Member yang sedang live streaming |
| `GET /api/jkt48/live/idn` | Live streaming dari IDN saja |
| `GET /api/jkt48/theater` | Jadwal pertunjukan teater |
| `GET /api/jkt48/news` | Berita terbaru |
| `GET /api/jkt48/events` | Daftar event |
| `GET /api/jkt48/birthday` | Ulang tahun member |
