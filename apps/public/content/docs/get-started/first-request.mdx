## Membuat Request Pertama

Setelah mendapatkan API key, saatnya membuat request pertamamu ke JKT48Connect API.

### Struktur Request

Semua request ke JKT48Connect API menggunakan format berikut:

```
GET https://v2.jkt48connect.com/api/jkt48/{endpoint}?apikey=YOUR_API_KEY
```

| Komponen | Deskripsi |
|----------|-----------|
| `https://v2.jkt48connect.com` | Base URL |
| `/api/jkt48/` | Prefix semua endpoint |
| `{endpoint}` | Nama endpoint (misalnya `members`, `live`) |
| `?apikey=` | Query parameter untuk autentikasi |

### Contoh: Mengambil Data Member

#### Menggunakan cURL

```bash
curl "https://v2.jkt48connect.com/api/jkt48/members?apikey=YOUR_API_KEY"
```

#### Menggunakan JavaScript (Fetch)

```javascript
const API_KEY = 'YOUR_API_KEY';

async function getMembers() {
  try {
    const response = await fetch(
      `https://v2.jkt48connect.com/api/jkt48/members?apikey=${API_KEY}`
    );
    
    if (!response.ok) {
      throw new Error(`Error: ${response.status}`);
    }
    
    const members = await response.json();
    
    // Tampilkan nama semua member
    members.forEach(member => {
      console.log(`${member.name} - ${member.generation}`);
    });
    
    return members;
  } catch (error) {
    console.error('Gagal mengambil data:', error.message);
  }
}

getMembers();
```

#### Menggunakan Python

```python
import requests

API_KEY = 'YOUR_API_KEY'

def get_members():
    try:
        response = requests.get(
            f"https://v2.jkt48connect.com/api/jkt48/members?apikey={API_KEY}"
        )
        response.raise_for_status()
        
        members = response.json()
        
        # Tampilkan nama semua member
        for member in members:
            print(f"{member['name']} - {member.get('generation', 'N/A')}")
        
        return members
    except requests.exceptions.RequestException as e:
        print(f"Gagal mengambil data: {e}")

get_members()
```

### Contoh: Cek Member yang Sedang Live

```javascript
const API_KEY = 'YOUR_API_KEY';

async function checkLive() {
  const response = await fetch(
    `https://v2.jkt48connect.com/api/jkt48/live?apikey=${API_KEY}`
  );
  const liveData = await response.json();
  
  if (liveData.length === 0) {
    console.log('Tidak ada member yang sedang live saat ini.');
  } else {
    liveData.forEach(member => {
      console.log(`🔴 ${member.name} sedang live di ${member.type}`);
      console.log(`   Mulai: ${member.started_at}`);
    });
  }
}

checkLive();
```

### Menangani Error

Pastikan untuk selalu menangani kemungkinan error:

| HTTP Status | Deskripsi |
|-------------|-----------|
| `200` | Sukses — data berhasil dikembalikan |
| `403` | Forbidden — API key tidak valid |
| `404` | Not Found — endpoint tidak ditemukan |
| `429` | Too Many Requests — rate limit terlampaui |
| `500` | Server Error — coba lagi nanti |

```javascript
async function safeRequest(endpoint) {
  try {
    const response = await fetch(
      `https://v2.jkt48connect.com/api/jkt48/${endpoint}?apikey=${API_KEY}`
    );
    
    if (response.status === 403) {
      throw new Error('API key tidak valid. Periksa kembali API key-mu.');
    }
    
    if (response.status === 429) {
      throw new Error('Terlalu banyak request. Tunggu sebentar lalu coba lagi.');
    }
    
    if (!response.ok) {
      throw new Error(`HTTP Error: ${response.status}`);
    }
    
    return await response.json();
  } catch (error) {
    console.error(error.message);
  }
}
```
