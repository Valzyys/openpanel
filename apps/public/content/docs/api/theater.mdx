## GET /api/jkt48/theater

Endpoint ini mengembalikan data jadwal pertunjukan teater JKT48 yang akan datang dan yang sudah berlalu.

### Request

```
GET https://v2.jkt48connect.com/api/jkt48/theater?apikey=YOUR_API_KEY
```

| Parameter | Tipe | Wajib | Deskripsi |
|-----------|------|-------|-----------|
| `apikey` | string | ✅ | API key untuk autentikasi |

### Contoh Request

```bash
curl "https://v2.jkt48connect.com/api/jkt48/theater?apikey=YOUR_API_KEY"
```

### Contoh Response

```json
[
  {
    "title": "Aturan Anti Cinta",
    "setlist": "Pajama Drive",
    "date": "2025-04-10",
    "time": "19:00",
    "venue": "JKT48 Theater",
    "members": [
      "Fritzy",
      "Shani",
      "Christy"
    ],
    "is_upcoming": true
  }
]
```

### Struktur Response

| Field | Tipe | Deskripsi |
|-------|------|-----------|
| `title` | string | Judul pertunjukan |
| `setlist` | string | Nama setlist yang ditampilkan |
| `date` | string | Tanggal pertunjukan (YYYY-MM-DD) |
| `time` | string | Waktu mulai pertunjukan |
| `venue` | string | Lokasi pertunjukan |
| `members` | array | Daftar nama member yang tampil |
| `is_upcoming` | boolean | `true` jika pertunjukan belum berlangsung |

### Contoh Penggunaan

#### JavaScript

```javascript
const API_KEY = 'YOUR_API_KEY';

async function getTheaterSchedule() {
  const response = await fetch(
    `https://v2.jkt48connect.com/api/jkt48/theater?apikey=${API_KEY}`
  );
  const schedule = await response.json();
  
  // Filter pertunjukan yang akan datang
  const upcoming = schedule.filter(show => show.is_upcoming);
  
  console.log(`🎭 ${upcoming.length} pertunjukan yang akan datang:\n`);
  
  upcoming.forEach(show => {
    console.log(`📅 ${show.date} ${show.time}`);
    console.log(`   ${show.title} — ${show.setlist}`);
    console.log(`   📍 ${show.venue}`);
    console.log(`   👥 ${show.members.join(', ')}\n`);
  });
}

getTheaterSchedule();
```

#### Python

```python
import requests

API_KEY = 'YOUR_API_KEY'

def get_theater_schedule():
    response = requests.get(
        f"https://v2.jkt48connect.com/api/jkt48/theater?apikey={API_KEY}"
    )
    response.raise_for_status()
    schedule = response.json()
    
    # Filter pertunjukan yang akan datang
    upcoming = [s for s in schedule if s.get('is_upcoming', False)]
    
    print(f"🎭 {len(upcoming)} pertunjukan yang akan datang:\n")
    
    for show in upcoming:
        print(f"📅 {show['date']} {show['time']}")
        print(f"   {show['title']} — {show['setlist']}")
        print(f"   📍 {show['venue']}")
        print(f"   👥 {', '.join(show['members'])}\n")

get_theater_schedule()
```

### Tips

- Data jadwal teater diperbarui secara real-time
- Gunakan field `is_upcoming` untuk memfilter pertunjukan yang akan datang
- Field `members` berisi daftar nama member yang dijadwalkan tampil
