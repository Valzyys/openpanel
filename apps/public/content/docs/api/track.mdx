## GET /api/jkt48/live

Endpoint ini mengembalikan data semua member JKT48 yang sedang live streaming di semua platform yang didukung (IDN Live, Showroom, YouTube).

### Request

```
GET https://v2.jkt48connect.com/api/jkt48/live?apikey=YOUR_API_KEY
```

| Parameter | Tipe | Wajib | Deskripsi |
|-----------|------|-------|-----------|
| `apikey` | string | ✅ | API key untuk autentikasi |

### Contoh Response

### Struktur Response

| Field | Tipe | Deskripsi |
|-------|------|-----------|
| `name` | string | Nama member |
| `img` | string | URL gambar utama/thumbnail |
| `img_alt` | string | URL gambar alternatif/avatar |
| `url_key` | string | Identifier unik untuk URL member |
| `slug` | string | Slug dari live stream saat ini |
| `room_id` | number | ID room streaming |
| `is_graduate` | boolean | Apakah member sudah graduate |
| `is_group` | boolean | Apakah ini live grup/bersama |
| `chat_room_id` | string | ID chat room untuk live stream |
| `started_at` | string | Waktu mulai live (format ISO 8601) |
| `streaming_url_list` | array | Daftar URL streaming yang tersedia |
| `type` | string | Platform: `"idn"`, `"showroom"`, atau `"youtube"` |

### Streaming URL List Object

| Field | Tipe | Deskripsi |
|-------|------|-----------|
| `label` | string | Label kualitas (mis: `"original"`, `"720p"`) |
| `quality` | number | Level kualitas (1 = tertinggi) |
| `url` | string | URL stream (biasanya HLS `.m3u8`) |

## GET /api/jkt48/live/idn

Endpoint khusus untuk mengambil data live streaming dari **IDN Live** saja.

### Request

```
GET https://v2.jkt48connect.com/api/jkt48/live/idn?apikey=YOUR_API_KEY
```

Response format sama dengan `/api/jkt48/live`, tetapi hanya mengembalikan data dari platform IDN.

---

## Platform yang Didukung

| Platform | Type Value | Deskripsi |
|----------|-----------|-----------|
| IDN Live | `"idn"` | Platform live streaming Indonesia |
| Showroom | `"showroom"` | Platform live streaming interaktif |
| YouTube | `"youtube"` | Live stream dan premiere YouTube |

## Contoh Penggunaan

### JavaScript — Tampilkan Member yang Sedang Live

```javascript
const API_KEY = 'YOUR_API_KEY';
const BASE_URL = 'https://v2.jkt48connect.com';

async function getLiveMembers() {
  try {
    const response = await fetch(`${BASE_URL}/api/jkt48/live?apikey=${API_KEY}`);
    
    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }
    
    const data = await response.json();
    
    if (data.length === 0) {
      console.log('Tidak ada member yang sedang live saat ini.');
      return;
    }
    
    console.log(`🔴 ${data.length} member sedang live!\n`);
    
    // Kelompokkan berdasarkan platform
    const platforms = {};
    data.forEach(member => {
      if (!platforms[member.type]) platforms[member.type] = [];
      platforms[member.type].push(member);
    });
    
    Object.entries(platforms).forEach(([platform, members]) => {
      console.log(`📺 ${platform.toUpperCase()} (${members.length} member):`);
      members.forEach(member => {
        const startedAt = new Date(member.started_at);
        console.log(`   • ${member.name} — mulai ${startedAt.toLocaleTimeString()}`);
      });
    });
    
    return data;
  } catch (error) {
    console.error('Error:', error.message);
  }
}

getLiveMembers();
```

### Python — Monitor Live dengan Grouping per Platform

```python
import requests
from datetime import datetime

API_KEY = 'YOUR_API_KEY'
BASE_URL = 'https://v2.jkt48connect.com'

def get_live_members():
    try:
        response = requests.get(f"{BASE_URL}/api/jkt48/live?apikey={API_KEY}")
        response.raise_for_status()
        data = response.json()
        
        if not data:
            print("Tidak ada member yang sedang live saat ini.")
            return
        
        print(f"🔴 {len(data)} member sedang live!\n")
        
        # Kelompokkan berdasarkan platform
        platforms = {}
        for member in data:
            platform = member['type']
            if platform not in platforms:
                platforms[platform] = []
            platforms[platform].append(member)
        
        for platform, members in platforms.items():
            print(f"📺 {platform.upper()} ({len(members)} member):")
            for member in members:
                started = datetime.fromisoformat(
                    member['started_at'].replace('Z', '+00:00')
                )
                print(f"   • {member['name']} — mulai {started.strftime('%H:%M:%S')}")
        
        return data
    except requests.exceptions.RequestException as e:
        print(f"Error: {e}")

get_live_members()
```

### Tips

- Response berupa **array kosong** `[]` jika tidak ada member yang sedang live
- Gunakan field `type` untuk memfilter berdasarkan platform
- Field `streaming_url_list` berisi URL HLS yang bisa diputar di video player
- `started_at` dalam format ISO 8601 UTC
