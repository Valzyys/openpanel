## GET /api/jkt48/members

Endpoint ini mengembalikan daftar lengkap semua member JKT48, termasuk member aktif, trainee, dan member yang sudah graduate.

### Request

```
GET https://v2.jkt48connect.com/api/jkt48/members?apikey=YOUR_API_KEY
```

| Parameter | Tipe | Wajib | Deskripsi |
|-----------|------|-------|-----------|
| `apikey` | string | ✅ | API key untuk autentikasi |

### Contoh Request

```bash
curl "https://v2.jkt48connect.com/api/jkt48/members?apikey=YOUR_API_KEY"
```

### Contoh Response

### Struktur Response

| Field | Tipe | Deskripsi |
|-------|------|-----------|
| `name` | string | Nama lengkap member |
| `img` | string | URL foto profil member |
| `generation` | string | Generasi member (mis: "JKT48 Gen 12") |
| `status` | string | Status member: `active`, `trainee`, `graduated` |
| `is_graduate` | boolean | `true` jika member sudah graduate |

### Contoh Penggunaan

#### JavaScript

```javascript
const API_KEY = 'YOUR_API_KEY';

async function getMembers() {
  const response = await fetch(
    `https://v2.jkt48connect.com/api/jkt48/members?apikey=${API_KEY}`
  );
  const members = await response.json();
  
  // Filter hanya member aktif
  const activeMembers = members.filter(m => !m.is_graduate);
  console.log(`Total member aktif: ${activeMembers.length}`);
  
  activeMembers.forEach(member => {
    console.log(`${member.name} (${member.generation})`);
  });
}

getMembers();
```

#### Python

```python
import requests

API_KEY = 'YOUR_API_KEY'

def get_members():
    response = requests.get(
        f"https://v2.jkt48connect.com/api/jkt48/members?apikey={API_KEY}"
    )
    response.raise_for_status()
    members = response.json()
    
    # Filter hanya member aktif
    active = [m for m in members if not m.get('is_graduate', False)]
    print(f"Total member aktif: {len(active)}")
    
    for member in active:
        print(f"{member['name']} ({member.get('generation', 'N/A')})")

get_members()
```

#### PHP

```php
<?php
$apiKey = 'YOUR_API_KEY';
$url = "https://v2.jkt48connect.com/api/jkt48/members?apikey={$apiKey}";

$response = file_get_contents($url);
$members = json_decode($response, true);

// Filter member aktif
$activeMembers = array_filter($members, function($m) {
    return !$m['is_graduate'];
});

echo "Total member aktif: " . count($activeMembers) . "\n";

foreach ($activeMembers as $member) {
    echo "{$member['name']} ({$member['generation']})\n";
}
?>
```

### Tips

- Data member di-update secara berkala mengikuti informasi resmi dari JKT48
- Gunakan field `is_graduate` untuk memfilter member aktif dan alumni
- Response berupa array JSON, jadi pastikan parsing-mu mendukung array
