## GET /api/jkt48/news

Endpoint ini mengembalikan berita dan pengumuman terbaru dari JKT48.

### Request

```
GET https://v2.jkt48connect.com/api/jkt48/news?apikey=YOUR_API_KEY
```

| Parameter | Tipe | Wajib | Deskripsi |
|-----------|------|-------|-----------|
| `apikey` | string | ✅ | API key untuk autentikasi |

### Contoh Response

```json
[
  {
    "title": "JKT48 11th Anniversary Concert",
    "content": "JKT48 akan mengadakan konser ulang tahun ke-11...",
    "date": "2025-04-01",
    "image": "https://jkt48.com/images/news/anniversary.jpg",
    "url": "https://jkt48.com/news/detail/id/1234"
  }
]
```

### Struktur Response

| Field | Tipe | Deskripsi |
|-------|------|-----------|
| `title` | string | Judul berita |
| `content` | string | Isi/ringkasan berita |
| `date` | string | Tanggal publikasi |
| `image` | string | URL gambar berita |
| `url` | string | Link ke berita lengkap |

### Contoh Penggunaan

```javascript
const API_KEY = 'YOUR_API_KEY';

async function getLatestNews() {
  const response = await fetch(
    `https://v2.jkt48connect.com/api/jkt48/news?apikey=${API_KEY}`
  );
  const news = await response.json();
  
  console.log('📰 Berita Terbaru JKT48:\n');
  
  news.forEach(article => {
    console.log(`📌 ${article.title}`);
    console.log(`   📅 ${article.date}`);
    console.log(`   🔗 ${article.url}\n`);
  });
}

getLatestNews();
```

## GET /api/jkt48/events

Endpoint ini mengembalikan daftar event dan off-air show JKT48.

### Request

```
GET https://v2.jkt48connect.com/api/jkt48/events?apikey=YOUR_API_KEY
```

| Parameter | Tipe | Wajib | Deskripsi |
|-----------|------|-------|-----------|
| `apikey` | string | ✅ | API key untuk autentikasi |

### Contoh Response

```json
[
  {
    "title": "JKT48 HS Event",
    "date": "2025-04-15",
    "venue": "Mall Kota Kasablanka",
    "description": "Handshake event bersama member JKT48",
    "members": ["Shani", "Fritzy", "Christy"]
  }
]
```

### Struktur Response

| Field | Tipe | Deskripsi |
|-------|------|-----------|
| `title` | string | Nama event |
| `date` | string | Tanggal event |
| `venue` | string | Lokasi event |
| `description` | string | Deskripsi event |
| `members` | array | Daftar member yang berpartisipasi |

### Contoh Penggunaan

```javascript
const API_KEY = 'YOUR_API_KEY';

async function getEvents() {
  const response = await fetch(
    `https://v2.jkt48connect.com/api/jkt48/events?apikey=${API_KEY}`
  );
  const events = await response.json();
  
  console.log('🎪 Event JKT48:\n');
  
  events.forEach(event => {
    console.log(`🎯 ${event.title}`);
    console.log(`   📅 ${event.date}`);
    console.log(`   📍 ${event.venue}`);
    console.log(`   📝 ${event.description}\n`);
  });
}

getEvents();
```

```python
import requests

API_KEY = 'YOUR_API_KEY'

def get_events():
    response = requests.get(
        f"https://v2.jkt48connect.com/api/jkt48/events?apikey={API_KEY}"
    )
    response.raise_for_status()
    events = response.json()
    
    print("🎪 Event JKT48:\n")
    
    for event in events:
        print(f"🎯 {event['title']}")
        print(f"   📅 {event['date']}")
        print(f"   📍 {event.get('venue', 'TBA')}")
        print(f"   📝 {event.get('description', '')}\n")

get_events()
```

### Tips

- Berita diurutkan dari yang terbaru
- Event mencakup handshake event, konser, dan off-air show
- Beberapa event mungkin memiliki field `members` yang berisi daftar member yang berpartisipasi
